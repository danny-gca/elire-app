# Sécurité

## Signaler une faille

Ne publiez pas de faille dans un ticket public.

Utilisez le [signalement privé de GitHub](../../security/advisories/new) (onglet **Security**, puis **Report a vulnerability**). Seul le mainteneur voit le rapport.

Indiquez :

- ce qui est touché (app mobile, site web, données, chaîne de build) ;
- comment reproduire ;
- l'impact possible.

Réponse visée sous 7 jours. Le correctif est publié avant toute divulgation.

## Hors champ

Une erreur dans les données (proposition, vote, source) n'est pas une faille : ouvrez un ticket [« Erreur dans les données »](../../issues/new?template=erreur-donnees.yml).

## Versions suivies

Seule la dernière version publiée (branche `main`) reçoit des correctifs.
